# ツールは Tavily 検索 + fetch + Think の workspace ツール

自前で有効にするのは、自作の Tavily 検索ツールと Think の `fetch` ツール（`createFetchTools`）の2つ。これに加えて **Think の workspace ツールが自動で有効になる**ので、モデルが使えるツールはこの2つだけではない（後述）。

当初は「ツールは初期実装ではWeb検索のみ」としていたが、`@cloudflare/think@0.16.0` に Web検索ツールは存在しない。提供されるのは `workspace` / `fetch` / `browser` / `execute` / `sandbox` / `extensions` / MCP であり、検索は自前で用意する必要があった。

## Considered Options

- **Brave Search API**: 超過分が $5/1,000クエリで Tavily より安いが、返るのはリンク一覧のみ。本文を読むには `fetch` での追いかけが必須になり、往復とトークンが増える。
- **`browser` ツール（Cloudflare Browser Rendering）**: 外部APIキーは不要だがbindingが有料で、検索するには検索エンジンをスクレイプする形になり不安定。
- **ツール無し**: 最小構成にはなるが、Slackで「調べて」に応えられない。

Tavily は無料枠が月1,000クレジット（クレジットカード不要）、超過分は $0.008/クレジット。LLM向けに設計されていて検索結果とともに本文を抽出して返すため、`fetch` での追いかけ回数が減る。`fetch` も併せて有効にするのは、Slackではユーザーが直接URLを貼って「これ要約して」と頼む頻度が高いため。

## workspace ツールは自動で有効になる（明示的に許容する）

Think は `this.workspace` を全エージェントに与え、**`read` / `write` / `edit` / `list` / `find` / `grep` / `delete` / `bash` を自動でモデルへ公開する**。opt-in ではなく既定で入るため、上の2つだけを登録したつもりでも実際にはこれらも使える。

当初この文書は「有効にするのは2つ」とだけ書いており、自動で増える分を記述していなかった。preview で bot が「Bashスクリプトの実行ができます」と自己紹介し、時刻を「実行環境のシステム時計で確認しました」と答えたことで発覚した（2026-08-29）。

**これを止めずに受け入れる。** 仮想ファイルシステムとシェルは、Slackから「ちょっと計算して」「表を整形して」といった依頼に応えるうえで有用で、追加コストも無いため。

- `bash` は `just-bash` によるサンドボックスで、実体は **DO SQLite 上の仮想ファイルシステム**。ホストのシェルではなく、Worker の外には出られない
- Session は Thread ごとに分かれる（ADR 0002）ので、workspace も Thread ごとに独立する
- 止めたくなった場合、README にあるフラグは `workspaceBash = false`（bash のみ）。`read` / `write` 等をまとめて切る公式フラグは見当たらない

## Consequences

- `TAVILY_API_KEY` が secret に増える
- ADR 0007（tool_result の compaction）は Tavily と `fetch` の出力を主な対象とする。どちらも出力が大きくなりやすい
- **モデルが自分の能力として workspace ツールを宣伝する。** 毎ターン system prompt に capability ブロックが足される（トークンを消費する）うえ、ユーザーが「ファイルを作って」と頼む導線が生まれる。この製品の主目的（スレッドでの会話・検索・URL要約）とは別の期待を持たれうる
- **ACL は無い**（§6 信頼境界）。ワークスペースに居る人は誰でもこれらのツールを使える。「検証用の個人ワークスペースに手動招待でのみ入れる」という前提に依存している点は、ツールが増えたぶん重くなっている。他ワークスペースへ展開するなら、レート制限と併せてここを再検討する
